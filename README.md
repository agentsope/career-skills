把"我就做了个小组作业""帮老师整理过数据"这种你觉得拿不出手的经历,像聊天一样讲给小译听,它帮你理清、说清、写成简历。

## 小译能帮你

<img src="assets/mascots/owl-think.png" alt="小译拿放大镜:帮你找准该投的岗位" width="46" align="left">

**找准该投的岗位** —— 不知道投什么,它帮你定方向,还真的上网帮你找在招的岗、看懂招聘要求、点出你还差什么。

<br clear="left">

<img src="assets/mascots/owl-magic.png" alt="小译挥魔法棒:把经历翻译成岗位语言" width="46" align="left">

**把经历翻译成「岗位语言」** —— 再普通的经历,也帮你挖出亮点,说成招聘方听得懂的话。这是小译的招牌本事。

<br clear="left">

<img src="assets/mascots/owl-resume.png" alt="小译举简历:帮你写出能直接投的简历" width="46" align="left">

**写出能直接投的简历** —— 把亮点磨成有力的简历条目,再按你要投的岗位,组装成一份成稿。

<br clear="left">

## 六个小帮手,卡在哪步用哪个

| Skill | 作用 | 触发关键词 |
|---|---|---|
| [career-role-finder](skills/career-role-finder/) | 定方向 + 上网找真实在招岗位 | 投什么、找实习、在招、求职方向 |
| [career-jd-analyzer](skills/career-jd-analyzer/) | 看懂招聘要求,点破"潜台词" | JD、岗位要求、能不能投、这岗要什么 |
| [career-gap-planner](skills/career-gap-planner/) | 还差什么、怎么补、要多久 | 差什么、该学什么、怎么补、学习计划 |
| [career-experience-mapper](skills/career-experience-mapper/) | 把经历翻译成招聘方听得懂的话 | 简历、经历、实习、转专业、这段能写吗 |
| [career-bullet-builder](skills/career-bullet-builder/) | 磨成简历上一行就有力的条目 | bullet、润色简历、改简历、量化 |
| [career-resume-tailor](skills/career-resume-tailor/) | 按岗位组装成能直接投的简历 | 简历投递、简历太长、投递版本、一页简历 |

## 它还能真的上网,帮你找岗位

别的工具只会"教你怎么写";小译里的 **role-finder 会真的联网**——去[官方校招官网](https://jobs.bytedance.com/campus)、[牛客汇总](https://www.nowcoder.com/jobs/school/schedule)、[GitHub Campus2026 聚合仓](https://github.com/namewyf/Campus2026) 这些地方,**搜到此刻在招、对得上你的真实岗位,给你真链接**。搜不到就老实说,绝不编个假的糊弄你;已经截止 / 下线的也会主动剔除。

> **比如你说:** 我计算机大三、会 Python,想在北京找暑期数据实习。
>
> **小译:** 建议你主攻「数据分析实习」(够得着);我联网找到几个在招的——
> · 某公司 · 数据分析实习 — 真实链接(截至 X 月,投递前自行确认)
> · …(已截止 / 下线的不会塞给你)

## 说好的:绝不替你瞎编

没有的就老实说没有,绝不替你编公司、编经历、编数字。**面试一问就穿帮的漂亮话,坑的是你。** 这是小译的底线。

## 三步开始用

1. 装好 [Claude Code](https://docs.claude.com/en/docs/claude-code)
2. 在终端跑一行(其余帮手见 [install.md](install.md)):
   ```bash
   npx skills add agentsope/career-skills/skills/career-experience-mapper
   ```
3. 直接跟它说你的情况,比如:
   > 我没实习,课上做过一个社会企业的小组作业,想投项目助理,这能写进简历吗?
