# career-gap-planner · 告诉你还差什么、怎么补

简体中文 · [English](README.en.md)

> **先告诉你哪些补得动、哪些别耗,再给能落地的路——不灌鸡汤,不画饼。**

对照你想去的岗位,看你还差什么、哪些补得动,该怎么补、要多久,并给你真实在用的学习资源。

## 它能帮你做什么

- 分清哪些差距补得动、哪些短期补不上(别在补不上的事上耗时间)
- 给能落地的补强步骤 + 大概要多久(不画"7 天精通"的饼)
- 推真实在用的学习资源(不瞎给课名)

## 举个例子

你说想投数据分析实习,但只会 Excel → 它说:最该先补 SQL,专注大概 3–4 周能用,顺手做个小项目正好写进简历;至于 JD 里"3 年经验",实习岗本来就不卡,别被吓退。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-gap-planner
```

然后直接跟 Claude 说,比如:

> 我想投数据分析实习,但只会 Excel,还差什么?该怎么补?

## 它的底线

补不上的就直说、给别的路,不灌"努力就能"的鸡汤;资源只给真搜到的,不编。
