# 找学习资源 · resource-finding

学习资源**联网现找**,不写死清单(清单会过时),更**不编链接**。本文件讲去哪找、怎么评估、红线在哪。

> **红线(no-fabrication 的资源延伸):** 推荐的任何课程 / 视频 / 文档 / 仓库,必须是**真实搜到、链接可达**的。搜不到合适的 → 明说"没搜到对口的,你平时用哪个平台?我去那找",**绝不**凭印象编一个像样的课程名 + 假链接。

---

## 1. 按类型去哪找(真实平台,稳定主站)

| 类型 | 平台(主站) | 适合 |
|---|---|---|
| 免费视频课 | 哔哩哔哩 bilibili.com | 入门、国内最丰富,口碑课多 |
| 系统课(含证书) | 中国大学MOOC icourse163.org · Coursera coursera.org · edX edx.org | 系统学、名校课 |
| 官方文档 / 教程 | 各语言/工具**官方文档**(最权威、最新) · MDN developer.mozilla.org | 准确、不过时 |
| 实践 / 项目 | GitHub github.com · Kaggle kaggle.com(数据) · LeetCode leetcode.cn(算法) | 动手、攒作品 |
| 书 | 经典教材(按方向) | 体系化 |

> 具体某门课 / 某个仓库的链接**运行时联网搜**,因为热门资源和链接会变;上面是稳定主站入口,不是某门课的固定链接。

---

## 2. 怎么找(运行时)

1. 按缺口 `WebSearch` 当前口碑资源(如"SQL 入门 B站 推荐 2025""数据分析 公开数据集 练手")。
2. 给 **1-2 个最对口**的真实链接(别堆一长串,呼应结果优先)。
3. 标注来源 + 大致时间 / 是否免费,方便用户判断。

---

## 3. 怎么评估一个资源值不值得推

- **对口**:是否正好补这个缺口、到所需程度(别推"精通级"给只需入门的)。
- **新**:更新时间近不近(技术类尤其,过时教程坑人)。
- **口碑 / 完成度**:评价、是否成体系、能不能跟到底。
- **可得性**:免费 / 付费、要不要登录;优先低门槛。

---

## 4. 搜不到 / 抓不到怎么办

- 如实说:"我没搜到特别对口又靠谱的,你平时习惯用哪个平台(B站 / MOOC / 极客时间…)?我去那边找。"
- 或给方向性建议(看官方文档 + 做项目)而不给具体假链接。
- **任何写出来的链接都必须是真搜到的;来源 + 时间如实标。**

---

## 5. 别只给"看的",要给"做的"

资源不只是课。每个缺口至少配一个**实践入口**(一个练手项目 / 一个数据集 / 一个 repo),因为补强的终点是**产出能写进简历的真实项目**(见 `learning-paths.md`),不是"看完课"。
