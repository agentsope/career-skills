# career-gap-planner · tell you what you're missing and how to close it

[简体中文](README.md) · English

> **First it tells you what's worth closing and what to skip, then gives you a path you can actually walk — no pep talk, no empty promises.**

Against the role you want, it shows what you're missing, what's closable, how to close it and how long it takes — with real, currently-used learning resources.

## What it does for you

- Separates closable gaps from ones you can't close short-term (don't waste time on the latter)
- Gives concrete steps + a realistic timeframe (no "master it in 7 days" fantasy)
- Recommends real, currently-used learning resources (no made-up course names)

## A quick example

You want a data-analysis internship but only know Excel → it says: close SQL first, about 3–4 weeks of focus to get usable, do a small project along the way that goes straight onto your résumé; as for the JD's "3 years' experience", internships don't gate on that — don't let it scare you off.

## How to use

Install it:

```bash
npx skills add agentsope/career-skills/skills/career-gap-planner
```

Then just tell Claude, e.g.:

> I want a data-analysis internship but only know Excel — what am I missing, and how do I close it?

## Its bottom line

If something can't be closed, it says so and offers another route — no "just work hard" pep talk; resources are only the real ones it found, never invented.
