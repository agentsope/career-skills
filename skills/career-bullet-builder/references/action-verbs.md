# 强动词库 · action-verbs(中文简历)

HR 扫一条 bullet 只花几秒,**起头的动词**决定第一印象。"负责""参与""帮忙"是简历里最常见、也最削弱力度的开头。本库给出按职能分类的强动词、弱→强替换表,以及最关键的——**按真实贡献选档位**的诚信规则。

> 核心:动词层级必须**配得上真实贡献**。贡献小却用"主导",面试 deep-dive 一问就穿帮。Polish, never inflate。

---

## 1. 按职能分类的强动词

**领导 / 统筹**
> 主导、统筹、牵头、组织、协调、推动、带领、整合、调度

**分析 / 研究**
> 分析、调研、评估、梳理、拆解、复盘、建模、论证、归纳、诊断、测算

**执行 / 技术**
> 搭建、开发、实现、复现、设计、优化、迭代、部署、重构、测试、维护、自动化

**运营 / 增长**
> 运营、策划、推广、增长、转化、拉新、留存、统计、监测、运维

**沟通 / 输出**
> 撰写、汇报、呈现、对接、协商、培训、输出、整理、编辑、答疑

**成果 / 改进**
> 提升、降低、缩短、扩大、节省、达成、交付、改进、加速、简化

---

## 2. 弱→强替换表(最常用)

| 弱表达 | 问题 | 强表达(按真实情况选) |
|---|---|---|
| 负责 X | 像 JD、看不出动作 | 主导 / 统筹 / 搭建 / 梳理 X(看贡献档位) |
| 参与了 X | 模糊、贡献不明 | 作为 N 人小组成员承担 X 部分 / 协助完成 X |
| 帮忙 / 协助做 X | 太轻 | 协助完成 X(贡献小时保留)/ 独立完成 X(若属实) |
| 做了一个 X | 口语、无信息 | 搭建 / 复现 / 开发 / 设计 X |
| 整理资料 | 无成果 | 梳理 / 归纳 / 清洗 X 类资料,建立 Y |
| 做 PPT / 报告 | 工具动作 | 撰写 / 制作 X 份汇报材料,呈现 Y |
| 跟着教程复现了 X | 易被吹大 | 复现 X(并标注复现性质,见 no-fabrication) |
| 用了一些方法提升 | 空泛 | 引入 / 应用 [具体方法],[结果] |

---

## 3. 按 evidence 分档(诚信关键)

选动词前先问:**这件事我真实的角色是什么?** 按证据强弱选档,不够档就降级。

| 档位 | 动词 | 用的前提(必须有的证据) |
|---|---|---|
| **强档** | 主导、牵头、独立开发、设计、搭建 | 你真的定了方向 / 独立交付 / 是主要负责人,面试能讲清决策 |
| **中档** | 承担、负责(某模块)、分析、优化、撰写 | 团队中有你明确负责的部分,能说清你那块 |
| **保守档** | 协助、参与、支持、配合、整理 | 贡献有限 / 是辅助角色 / 证据不足时——**宁可降级也不夸大** |

**降级规则(默认从严):**
- 团队项目里没有"你定方向"的证据 → 不用"主导",用"承担/参与"。
- "我也不确定算不算我做的" → 用保守档或先问用户。
- 复现 / 跟教程 / 课程作业 → 用"复现/完成",并标注性质,不用"打造/上线"。

---

## 4. 要删掉的"伪强词"

这些是**形容词或态度**,不是动作,占位置又不可验证,直接删,用具体动作代替:

> 认真负责、积极主动、努力、热情、踏实、较强的 XX 能力、良好的 XX 意识

- ❌ `工作认真负责,具备较强的沟通能力。`
- ✅ `对接 3 个部门协调排期,推动项目按时交付。`(用动作证明"沟通能力",不自夸)

---

## 5. 同段多条:动词去重 + 排比

一段经历有多条 bullet 时:
- **不重复用同一个动词**(别条条都"负责")。
- 句式平行,动词都放句首,读起来有节奏。

例(同一实习,3 条):
```
· 搭建客户数据看板,整合 4 个来源的周报指标;
· 分析月度转化漏斗,定位 2 个流失环节并提出优化建议;
· 撰写复盘文档,沉淀为团队可复用的分析模板。
```
(搭建 / 分析 / 撰写——三个不同职能动词,平行起头。)

---

## 6. 输出时怎么用

- 先看用户原句的弱开头,用 §2 替换;再用 §3 校验档位是否配得上真实贡献。
- 给成品时顺带一句"把'负责'改成了'统筹',因为你提到是你定的排期"——让用户知道为什么改、改得对不对。
- 拿不准贡献档位 → 直接问("这部分是你定方向还是执行别人的安排?"),不替用户拔高。
