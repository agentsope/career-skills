# career-bullet-builder · 把经历磨成简历上有力的一行

简体中文 · [English](README.en.md)

> **你不是没东西写,是没把它写成 HR 停得下来的那一行。**

把粗糙的、或你自己写得很弱的简历句,打磨成一行就有力、又真实的条目。

## 它能帮你做什么

- 把"负责…""参与了…"这种没力气的句子,换成有力、具体的写法
- 没有漂亮数字也写得专业(不硬凑、不编)
- 一条经历给你两个版本,挑顺手的用

## 举个例子

- 你写:负责社团公众号运营,涨了一些粉丝。
- 它给:统筹社团公众号运营,策划每周内容排期与 3 次主题活动,带动粉丝稳定增长。

"涨了多少"它没替你编——你有真实数字,它再帮你加上。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-bullet-builder
```

然后直接跟 Claude 说,比如:

> 帮我把这条简历改得有力点:负责社团公众号,涨了一些粉丝。

## 它的底线

绝不替你编数字;面试一问就穿帮的漂亮话,不写。
