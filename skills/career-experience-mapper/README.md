# career-experience-mapper · 把经历翻译成招聘方听得懂的话

简体中文 · [English](README.en.md)

> **你不是没经历,是不会「翻译」。**

你觉得"我就做了个小组作业""帮老师整理过数据"拿不出手?其实里面藏着招聘方在意的能力,只是你没说对。把经历讲给它,它帮你挖出亮点、说成简历能用的话。

## 它能帮你做什么

- 看出一段经历到底体现了什么、值不值得写
- 把大白话、口语,翻译成招聘方读得懂的简历表达
- 没实习、转专业也能从课程 / 社团 / 兼职里挖出能写的东西

## 举个例子

- 你说:参与了一个关于社会企业的小组作业。
- 它给:分析某社会企业案例的财务可持续性与运营风险,提出成本控制建议(4 人课程小组)。

只是把你做的事说清楚了,没多加一个数字。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-experience-mapper
```

然后直接跟 Claude 说,比如:

> 我没实习,课上做过一个社会企业的小组作业,想投项目助理,这能写进简历吗?

## 它的底线

没有的绝不替你编;需要英文版,说一声也能给。
