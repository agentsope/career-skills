# JD 潜台词词典 · jd-subtext

JD 里有些话是"行话",字面之外有潜台词。本词典帮用户读懂言外之意,**避开坑**。

> **重要立场:这些是「常见信号」,不是「铁律」。** 每条都要标注"提示,建议向 HR / 实际核实",不替用户把话说死、不带他往最坏处臆断。目的是让他**会问对问题**,不是教他疑神疑鬼。

---

## 1. 强度 / 加班类

| JD 说法 | 常见潜台词(需核实) | 可问 HR |
|---|---|---|
| 能接受高强度工作 / 抗压能力强 | 加班可能较多 | "这个岗日常工作节奏、加班频率大概怎样?" |
| 弹性工作时间 | 可能没有固定下班点 | "弹性是指可晚到,还是常需晚走?" |
| 年轻有活力的团队 / 拼搏 / 狼性 | 加班文化、节奏快 | "团队平均工作时长?" |
| 适应快节奏 / 多线程 | 事多人少、常救火 | "这个岗同时推进几摊事?" |

## 2. 人手 / 资源类

| JD 说法 | 常见潜台词 | 可问 HR |
|---|---|---|
| 独当一面 / 独立负责 | 可能没人带、资源有限 | "这个岗有没有 mentor / 团队支持?" |
| 身兼数职 / 一人多岗 | 人手不足,什么都得干 | "主要职责和占比大概怎么分?" |
| 从 0 到 1 搭建 | 基础薄弱,需自己铺路 | "现在这块有基础吗,还是全新?" |

## 3. 薪资 / 回报类

| JD 说法 | 常见潜台词 | 可问 HR |
|---|---|---|
| 薪资面议 | 区间大 / 可能偏低 / 看人给 | "这个岗的薪资区间大概是?" |
| 薪资 5k–10k | 大概率按**下限**或看能力 | "应届/我这背景一般落在哪一档?" |
| 上不封顶 / 多劳多得 | 底薪可能低,靠提成 | "底薪和浮动大概比例?" |
| 提供广阔发展空间 | 现状可能一般,画饼 | "这个岗过去一两年的晋升 / 发展路径?" |

## 4. 职责 / 边界类

| JD 说法 | 常见潜台词 | 可问 HR |
|---|---|---|
| 其他领导交办事项 | 杂活兜底 | "这条大概占多少精力?" |
| 沟通协调能力强 | 跨部门扯皮多 | "这个岗主要和哪些团队对接?" |
| 服从公司安排 | 可能调岗 / 加任务 | "岗位职责稳定吗?" |

## 5. 硬门槛类(不是潜台词,是真卡)

这些**通常就是字面意思的硬卡**,别抱侥幸:
- "统招本科及以上""全日制":卡学历形式。
- "X 年以上经验":应届投这类多半被刷。
- "仅限 XX 专业""持 XX 证":硬性资格。

> 不满足硬门槛 → 如实评估,别硬投浪费简历;或在 `gap-planner` 里看怎么补。

---

## 6. 怎么用(给 Step 4)

- 命中词典 → 给用户 **1-2 个最值得注意**的提示(不要把整本词典倒给他)。
- 每条都带一句"这是常见信号,建议你核实",并配一个**能问 HR 的具体问题**。
- 不臆断、不劝退;让用户**带着问题去面试**,自己判断。
