# career-jd-analyzer · 帮你看懂一份招聘要求

简体中文 · [English](README.en.md)

> **JD 写得又虚又长,还夹着黑话。先看懂它,再决定投不投。**

把一份招聘要求翻成人话:它到底要什么、你该不该投,还帮你看穿那些"潜台词"。

## 它能帮你做什么

- 分清哪些是"硬性卡"(不满足别白投)、哪些只是加分
- 看穿招聘黑话——比如"能接受高强度"常意味着加班多、"薪资面议"常意味着区间大
- 判断以你的情况该不该投、还差什么,并给你能问 HR 的问题

## 举个例子

你把一个数据分析实习的链接发给它 → 它告诉你:核心要 SQL 和 Excel,硬门槛是学历;JD 里"快节奏"可能意味着加班,建议面试时问清工作强度。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-jd-analyzer
```

然后直接跟 Claude 说,比如:

> 帮我看看这个岗到底要什么、我能不能投:(贴上招聘链接或文字)

## 它的底线

只看你给的真实招聘信息;给不了它就说,绝不凭岗位名编一份出来糊弄你。
