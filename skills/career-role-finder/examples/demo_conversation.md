# Demo Conversations · career-role-finder

默认**结果优先**:先给主攻方向 + 几个真实在招,再按需展开。具体职位**联网实时找、给真实链接 + 抓取时间**;搜不到就**如实说、绝不编**。下例具体公司为**示意**(讲流程),真实用时是联网当下的结果。`(幕后)` 不出现在给用户的回复里。

---

## 场景 1 — 定方向 + 找在招(find)

**User:** 我文科大三,会 Excel,想做数据相关的,在北京找暑期实习。我能投什么?

**Skill:**(联网搜过后)

> 以你背景,建议**主攻「数据分析实习」**(门槛友好、够得着),也可看「运营数据 / 商业分析实习」;"数据分析师"那种社招岗先别碰(卡经验)。我联网找了下北京当前在招:
>
> · [某公司]数据分析实习 — 真实链接(截至 2026-05-26 在招,投递前自行确认)
> · [某公司]商业分析实习 — 真实链接(同上)
>
> 想多找几个 / 换个方向 / 把某个 JD 拆开看要求 / 看我还缺啥再投?说一声。

*(幕后:role-targeting 给主攻 + 相邻 + 劝退"冲一冲";F3 联网真实检索;每条标抓取时间;不夸匹配。)*

## 场景 2 — 联网抓不到(边界:绝不编岗位充数)

**User:** 帮我找几个杭州的产品经理实习,在招的。

**Skill:**(尝试联网,平台反爬 / 需登录,抓不全)

> 跟你说实话:我去搜了,但这几个招聘站反爬 / 要登录,**我没能直接抓到可靠的"在招"职位**——我不会随便编几个公司和链接充数(那样你白投、还可能上当)。
>
> 这么办,任选:
> 1. 你打开 **Boss直聘校园**(https://www.zhipin.com/school/)或 **实习僧**(https://resume.shixiseng.com/xiaozhao),搜"产品 实习 杭州",把看中的**职位链接**发我,我帮你拆 JD、看合不合适;
> 2. 我先帮你把**产品方向**定清楚(适合你的细分、简历该突出什么),等你拿到具体岗再深入。
>
> 你选哪个?

*(幕后:抓不到 → 如实说;绝不编岗位 / 链接;给真实平台入口 + 要链接 + 先给方向,三条真实退路。)*

## 场景 3 — 不知道适合做什么(explore)

**User:** 我快毕业了,但完全不知道自己适合干啥…

**Skill:**

> 别急,先从你**做过、不反感的事**反推。问你三件:① 哪门课 / 哪段经历做起来最不痛苦、甚至有点上头?② 更愿意跟"数据 / 逻辑"打交道,还是"人 / 内容"?③ 城市和实习时间有要求吗?
>
> 你答完我给你 2-3 个**够得着**的方向 + 各自能投的真实在招,有的放矢地试,不让你瞎海投。

*(幕后:explore;从兴趣 + 能力反推;先发散问、再聚焦;不强行联网凑岗位。)*

## 场景 4 — 让我打包票(边界)

**User:** 你直接给我找个"稳进、不卷、钱多"的岗呗。

**Skill:**

> "稳进 + 不卷 + 钱多"谁都想要,也正因如此基本不存在或极难——我不能为了顺你的话编一个出来。
>
> 但我能帮你找**性价比相对高、对你够得着**的真实方向和在招:你更看重哪个——离家近 / 成长快 / 起薪高 / 压力小?定个优先级,我按它去真实平台找。

*(幕后:不画饼、不编"完美岗";把模糊愿望转成可操作的优先级,再联网找真实的。)*
