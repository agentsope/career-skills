# 真实招聘平台与经验资源 · job-platforms

本 skill 针对**真实岗位**调简历。真实 JD / 岗位由用户提供链接,或运行时联网抓取。本文件给出**真实、稳定**的平台与资源入口。

> **铁律(no-fabrication 的链接延伸):**
> - 下列为真实平台 / 版块页(2026-05 联网确认可达,或公认主站)。
> - **具体职位、具体帖子的链接会过期**——一律**运行时实时抓取**用户的目标,不写死、不缓存。
> - **绝不编造 URL。** 抓不到 / 打不开 → 明说"没取到,请把链接发我",绝不凭印象生成一个像样的假链接。
> - 引用任何抓到的内容,如实标注来源与时间。

## 4. 最容易抓到完整内容的源(优先用这些)

实测:下面这些用 `WebFetch` 多能直接读到全文,比常反爬的 Boss / 实习僧详情页可靠得多。

- **公司官方校招官网** — 如 `jobs.bytedance.com/campus`、`join.qq.com`(腾讯)、`campus.163.com`(网易)、`campus.51job.com/<公司>`;JD 最准最新、正文可读,优先于第三方转载。
- **机构 / 国企 / 交易所 / 高校官网招聘页** — 交易所、银行、研究所、学校就业网;具体岗常能整页读到。
- **聚合页 / 汇总** — 牛客大厂校招汇总贴、GitHub 校招仓(如 `Campus2026`)、应届生求职网 `yingjiesheng.com`、`cn.indeed.com`、卡码投递表;结构化、带官方投递链接、网页可读。
- **学校就业网 / 院系内推群** — 校招信息最对口、常有内推。

## 5. 运行时怎么用(给 skill 的执行指引)

1. 用户说"投这个岗" → 先要**真实 JD 链接**;有链接 → 联网抓 JD 正文,提取关键词/要求。
2. 没链接 → 提示从上面平台找到目标职位,把链接发来;**不要**凭岗位名编一个 JD 或链接。
3. 抓取失败(登录墙/反爬/失效)→ 如实说明,请用户贴 JD 文本或截图。
4. 任何写进产出的链接,必须是真实抓到的;来源 + 时间如实标注。
