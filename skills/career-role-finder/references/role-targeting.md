# 岗位方向定位 · role-targeting

回答"我该投什么方向"。原则:**够得着 + 对得上 + 给退路**。不只推热门,不画够不着的饼,也不把人框死在一个方向。

---

## 1. 画像维度(Step 1 收齐)

- **专业 / 学历**:决定哪些岗硬性友好。
- **已有能力**:技能 + 可迁移能力(用 `career-experience-mapper` 的清单最准)。
- **经历**:实习 / 项目 / 课程 / 活动——看靠近哪类岗。
- **地点**:城市 / 能否去外地——直接影响在招量。
- **兴趣 / 行业倾向**:愿意做什么(别只看"好就业")。
- **约束**:实习还是校招、时间、是否接受跨方向。

> 缺关键项(尤其地点、实习/校招、能力底)就**直接问**,别替用户假设。

---

## 2. 匹配逻辑:三类方向一起给

不要只给一个"最佳"。给 **2-3 个**,覆盖不同可达性:

| 档 | 含义 | 例(文科+会Excel+想做数据) |
|---|---|---|
| **主攻(够得着)** | 能力/背景现在就对得上、门槛友好 | 数据分析实习、商业分析实习 |
| **相邻(顺带可投)** | 技能迁移一点就能投、扩大面 | 运营数据、市场研究、BI 助理 |
| **冲一冲(拔高)** | 现在差一截、补了能上 | 数据分析师(社招级)——需补 SQL/项目 |

- **可达性**最关键:别把"冲一冲"当主攻推,会让人海投被拒、受打击。
- 给每个方向一句**为什么适合你**(基于画像,不空夸)。

---

## 3. 特殊情形

- **转专业 / 零相关经验**:优先找**门槛友好的入口岗**(实习、应届、不卡专业的),用可迁移能力切入,别一上来推要资历的岗。
- **不知道适合做什么(explore)**:从"做过什么不反感 + 什么能力强"反推 2-3 个候选方向,先发散给选项,再聚焦。
- **目标过高 / 不现实**:如实说差距(回指 `gap-planner`),并给**相邻的现实替代**,不直接泼冷水也不假装可行。

---

## 4. 输出(给 Step 3 用)

```
directions:
  - { 方向, 档位(主攻/相邻/冲), 为什么适合你, 现实可达性 }
```

> 方向定了,Step 3 才去**联网**找这些方向的真实在招职位(见 `live-search.md`)。方向是方法论判断;具体岗位必须真实检索,不能凭方向"脑补"出人选岗位。
