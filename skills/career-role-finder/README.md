# career-role-finder · 帮你定方向、找在招的岗位

简体中文 · [English](README.en.md)

> **求职第一步不是改简历,是搞清楚「投什么」。**

不知道投什么?它根据你的情况帮你定方向,还真的上网帮你找当前在招的岗位。

## 它能帮你做什么

- 根据你的背景,给够得着的求职方向(不画饼、不只推热门)
- 真的上网找在招的岗位,给你真实链接
- 迷茫、转专业、没头绪,也能从头帮你理出方向

## 举个例子

你说"我 CS 大三、会 Python、想在北京找暑期数据实习" → 它建议主攻数据分析实习,并联网找几个当前在招的发给你(已经下线的会主动剔除)。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-role-finder
```

然后直接跟 Claude 说,比如:

> 我 CS 大三,会 Python,想在北京找暑期数据实习,我能投什么?帮我找找在招的。

## 它的底线

找不到真实在招的就说,绝不编公司或链接糊弄你;职位会下架,投递前自己再确认一下。
