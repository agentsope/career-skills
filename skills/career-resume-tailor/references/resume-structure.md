# 简历结构与格式 · resume-structure(国内)

整份简历的骨架:放哪些模块、什么顺序、多长、什么格式能过机器筛。单条 bullet 的打磨在 `career-bullet-builder`,这里只管**整份**。

---

## 1. 顶部信息栏

- **必放**:姓名、电话、邮箱、求职意向(目标岗位)。技术岗加 GitHub / 作品集链接(真实的)。
- **不放**:照片、出生日期、性别、婚姻、政治面貌、身份证号、籍贯。国内简历同样建议不放(除非岗位明确要求);省版面、避偏见。

---

## 2. 模块顺序(按人群)

**应届 / 在校(默认):**
```
信息栏 → 教育背景 → 实习经历 / 项目经历(最相关的在前)→ 技能 → 校园经历 / 荣誉
```
- 有**强相关实习** → 把"实习经历"提到"教育"之后、靠最前。
- 纯学生、无实习 → "项目/课程作业""校园经历"顶上,按与岗位相关性排。

**转专业 / 跨方向:** 把"项目/技能"前置(证明能力),弱化不相关的原专业课程细节。

**社招(有工作经验):** 信息栏 → 工作经历(倒序、占主体)→ 项目 → 技能 → 教育(简略)。

> 每个模块内部一律**时间倒序**(最近的在上),并写清 `时间 + 组织 + 角色`。

---

## 3. 长度

- **应届:一页**。装不下 → 砍最弱、最不相关的,而不是缩字号塞满。
- **社招:1-2 页**,经历多可放宽。
- 宁可少而精,不要凑满。HR 几秒扫一份,密密麻麻反而劝退。

---

## 4. ATS / 机器筛友好(整份层面)

- **单栏**布局;别用双栏/复杂表格(解析后顺序乱)。
- **标准模块标题**:教育背景 / 实习经历 / 项目经历 / 技能 / 校园经历——机器靠这些切分。别用花名当标题。
- 关键信息**别放页眉/页脚/文本框/图片**(多数解析器读不到)。
- **PDF 优先**(除非要求 Word);文件名 `姓名-岗位-学校.pdf`。
- 不用进度条/星级图标表示技能(机器读不懂、也不可信)→ 用文字 + 真实例证。

> 单条 bullet 内的关键词嵌入、长度、动词,见 `career-bullet-builder`;这里确保整份的结构和格式不丢分。

---

## 5. 各模块写法要点

- **教育**:学校、专业、学历、起止时间;GPA/排名**高**才放;相关课程**仅在与岗位强相关或经历太少时**精选几门,不罗列。
- **实习/项目**:每段 `时间 + 组织 + 角色` + 2-4 条成品 bullet(来自 bullet-builder),最有力的放第一条。
- **技能**:分类列真实掌握的(如 语言/工具/证书);命中目标 JD 的关键词;**没做过的不堆**。
- **校园/荣誉**:与岗位相关或能体现可迁移能力的才留;水活动删。

---

## 6. 自检

- [ ] 应届是否控制在一页?最弱的是否已砍?
- [ ] 模块标题是否标准、可被机器识别?
- [ ] 是否单栏、PDF、无图片承载关键信息?
- [ ] 照片/出生日期等合规项是否已移除?
- [ ] 每段是否倒序、含时间组织角色?最相关经历是否前置?
