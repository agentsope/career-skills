# career-resume-tailor · 把经历组装成能直接投的简历

简体中文 · [English](README.en.md)

> **一份简历投所有岗位,等于没对准任何一个。**

把一堆经历,按你要投的岗位取舍、排好,组装成一份能直接投出去的简历。

## 它能帮你做什么

- 按你要投的岗位,决定哪些经历放前面、哪些可以砍
- 应届简历砍到一页,排得清楚好读
- 同样的经历,投不同岗位各出一版

## 举个例子

你有一堆经历,想投运营管培——它帮你把最相关的提前、不相关的收短,排成一份一页简历;你再说"还想投数据岗",它给一版换个侧重的,经历不变、强调不同。

## 怎么用

装它:

```bash
npx skills add agentsope/career-skills/skills/career-resume-tailor
```

然后直接跟 Claude 说,比如:

> 帮我把这些经历组装成一份投运营管培的简历,再给我一版投数据岗的。

## 它的底线

只帮你取舍和强调,绝不替你编经历;要对的岗位由你给真实的,它不编假链接。
